# Project Documentation Context

- `.bob/agents/` contains specialist worker definitions.
- User-facing modes are defined in `custom_modes.yaml`.
- SmartBob is the router/orchestrator.
- BobOps coordinates engineering specialists.
- BobCompliance coordinates governance and assurance specialists.
- BobKT coordinates knowledge-transfer specialists.
- BobMigrate coordinates transformation specialists.
- Skills are reusable capabilities and should be loaded when relevant.
- Project-specific context belongs in the project profile and repository documentation.
- MCP configuration is project-local and should not be overwritten by the framework installer.
