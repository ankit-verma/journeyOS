# Funnel Analysis

1. Establish objective and scope.
2. Load only relevant project context.
3. Perform the capability using available tools.
4. Record evidence and assumptions.
5. Return concise results and next actions.
6. Escalate uncertainty when appropriate.

Never fabricate tool execution or results.
