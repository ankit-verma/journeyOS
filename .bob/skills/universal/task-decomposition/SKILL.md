# Task Decomposition

Decompose complex work into a dependency-aware task graph.

## Procedure
1. Establish scope and success criteria.
2. Discover relevant project evidence.
3. Identify assumptions and unknowns.
4. Execute with available tools.
5. Verify with appropriate sensors.
6. Return evidence, risks and next actions.
