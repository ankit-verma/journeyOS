# SmartBob Completion Contract

A project may be reported as complete only when the applicable evidence exists.

## Product
- [ ] Requested outcome implemented
- [ ] Critical user journeys verified
- [ ] Important assumptions documented

## Engineering
- [ ] Build succeeds
- [ ] Tests appropriate to the project pass
- [ ] Static/type/lint checks pass where applicable
- [ ] Independent review completed

## Security/Governance
- [ ] Relevant security checks completed
- [ ] Relevant privacy/compliance/licensing/accessibility checks completed
- [ ] Open risks recorded

## Delivery
- [ ] CI/CD path verified where applicable
- [ ] Deployment completed only with required authorization
- [ ] Post-deployment smoke checks pass

## Knowledge
- [ ] README/setup updated
- [ ] Architecture and operations docs updated
- [ ] KT/onboarding material updated

Each checked item must point to evidence in the project's execution record, artifact, test result, or verified endpoint.
