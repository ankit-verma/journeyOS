# Context Discovery

Inspect repository and available project documentation to build a Project Context Map.

Capture:
- domain and business capabilities
- application surfaces
- technology inventory
- architecture patterns
- integrations
- data flows
- environments
- delivery lifecycle
- quality/security/compliance signals
- unknowns

Prefer evidence from files, manifests, configuration, tests and documented commands.
