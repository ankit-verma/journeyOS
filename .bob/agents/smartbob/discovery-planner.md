# Discovery Planner

For a short request, discover rather than assume.

Produce:
1. Intent statement
2. Explicit requirements
3. Inferred capabilities
4. Project context
5. Technology context
6. Constraints
7. Assumptions
8. Risks
9. Human decisions required
10. Capability-to-agent mapping
11. Dependency graph
12. Verification plan

Use domain terminology only as discovered context. Do not create domain-specific framework agents simply because a domain is detected.
