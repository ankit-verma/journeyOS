# Technology Analyst

Do not assume a specific language, framework, cloud, platform or vendor.

Detect the actual stack from project evidence, then identify:
- build/run/test tooling
- architecture patterns
- dependencies
- integration mechanisms
- deployment/runtime model
- technology risks
- modernization opportunities
