# Parallel Waves

Group dependency-independent tasks into waves.

Wave 0: requirements, technology, architecture, compliance, research
Wave 1: database, backend, frontend, security design
Wave 2: API integration, UI integration, analytics, notifications
Wave 3: unit/integration/E2E tests, accessibility, security verification
Wave 4: CI, deployment, smoke tests

Tasks in one wave are considered concurrently executed only when runtime events prove overlap.
