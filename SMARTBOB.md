# SmartBob Framework v1 - Universal Operating Model

SmartBob is a portable capability-based agent framework intended to plug into modern software and business projects without requiring the framework to know the project's industry or technology in advance.

## Core model

Mode -> Agent -> Skill -> Tool -> Sensor -> Feedback

## Universal loop

EXPLORE -> PLAN -> EXECUTE -> VERIFY -> FEEDBACK

## Runtime discovery

At the beginning of meaningful work, SmartBob can discover:
- domain/business context
- product and user journeys
- application surfaces
- technology stack
- architecture
- integrations
- data
- infrastructure/runtime
- delivery lifecycle
- quality/security/compliance requirements

This avoids hard-coding an agent for every sector or vendor.

## Capability families

Engineering, architecture, development, testing, security, integrations, data, platform, reliability, compliance, research, executive communication, sales/growth, finance and knowledge transfer.

## Context discipline

Use targeted specialist delegation and compact artifacts/summaries rather than filling the main context with every tool result.

## Guides vs sensors

Guides steer behavior before action: rules, skills, agent instructions and project context.

Sensors provide feedback after action: tests, builds, lint, security scans, reviews, CI, accessibility checks, performance measurements and operational signals.
