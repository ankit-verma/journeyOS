# Agent vs Skill vs Mode vs Rule vs Sensor

Agent: WHO — a specialist responsibility and reasoning role.

Skill: WHAT — a reusable capability or procedure.

Mode: HOW — the user-facing operating posture.

Rule: MUST — persistent constraints and behavioral guidance.

Tool: WITH WHAT — the mechanism used to perform work.

Sensor: EVIDENCE — an objective signal about the result.

SmartBob hierarchy:
Mode -> Agent -> Skill -> Tool -> Sensor -> Feedback

Do not create a new agent merely because a new industry, vendor or technology appears. First ask whether an existing capability agent plus project context can handle it.
