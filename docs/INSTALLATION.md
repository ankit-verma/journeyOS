# Installation

1. Copy `.bob/` into a target Bob project.
2. Merge the framework AGENTS.md guidance with the project's existing AGENTS.md.
3. Open the project in Bob.
4. Confirm SmartBob is available as the default mode.
5. Configure a project adapter with architecture, commands and sensors.
6. Configure MCP separately using the exact supported server configuration.
7. Test SmartBob with a read-only exploration request before enabling write/deployment workflows.

If your Bob release uses a different custom_modes.yaml schema, adapt only the schema while retaining the SmartBob role model.
