Problem & Solution Statement
Problem
AI coding assistants require constant human orchestration — developers must manually decompose tasks, select tools, switch contexts, manage dependencies, track progress and verify results. Each project requires bespoke prompting, and teams lack reusable structures to encode hard-won patterns. When a team wants to build a complete product — authentication, database, REST API, admin dashboard, AI integration, deployment config, tests — they spend more time directing the AI than working on the product itself. Existing frameworks encode assumptions about industries, vendors or technologies, meaning they break the moment the project deviates from their expectations.
Solution
SmartBob is a universal, capability-based agent orchestration framework for IBM Bob. It replaces manual orchestration with a structured hierarchy: Mode → Agent → Skill → Tool → Sensor → Feedback. A single concise human prompt triggers autonomous context discovery, specialist agent selection, dependency-aware parallel execution, and sensor-verified delivery. The framework never hard-codes industries, vendors or technologies — it discovers them at runtime. Any project, any stack, any domain.
Real-world proof: JourneyOS
A single prompt — "Build a travel website called JourneyOS" — produced a fully deployed, production-grade travel platform: Node.js/Express backend (31 API routes), SQLite database (10 tables), responsive frontend, admin dashboard, JWT auth, AI chatbot with multi-provider failover, token tracking, live demos, tests, and Render deployment config — all autonomously orchestrated by SmartBob through IBM Bob.

Installation & Usage
Install (bash / macOS / Linux)
$ git clone https://github.com/smartbob/framework-v1
$ ./install-smartbob.sh /path/to/your/project
# Backs up existing .bob, preserves custom files
$ ./install-smartbob.sh /path/to/project --dry-run
Install (PowerShell / Windows)
PS> git clone https://github.com/smartbob/framework-v1
PS> .\install-smartbob.ps1 C:\path\to\project
# Or import custom_modes.yaml in Bob Settings
Step 1 — Install
Run installer script on your project
Existing .bob backed up automatically
mcp.json & settings.json preserved
Custom skills preserved
Step 2 — Configure
Open project in IBM Bob
Import custom_modes.yaml (Settings → Modes)
SmartBob appears as default mode
Add project adapter with stack context
Step 3 — Use
Start with one-sentence outcome prompt
SmartBob discovers context autonomously
Agents work in parallel waves
Sensors verify every deliverable

How SmartBob Built on IBM Bob
SmartBob is a framework layer over IBM Bob — it structures Bob's native capabilities into a repeatable, autonomous delivery system
IBM Bob Native Capabilities Used
Subagents — parallel independent context windows for concurrent work
Skills — reusable SKILL.md procedures auto-activated by context
Custom Modes — 10 operating personas via custom_modes.yaml
Subtasks — focused child tasks for scoped deliverables
Todo Lists — step tracking through complex multi-phase work
MCP Tools — Render deployment, external API integration
File Tools — write_file, apply_diff, search_and_replace for surgical edits
Execute Command — build, test, lint, server smoke tests
SmartBob Adds on Top of Bob
Capability registry — maps intent → agents + skills automatically
Dependency graph — proves which tasks can run in parallel
Execution model — EXPLORE→PLAN→EXECUTE→VERIFY loop
74 specialist agents — domain-neutral, capability-based roles
48 reusable skills — procedural guides across 6 families
Safe approval gates — escalation rules for irreversible actions
Project adapter — context profile that replaces bespoke prompting
One-prompt contract — human intent as outcome, not specification
"SmartBob is to IBM Bob what an operating system is to hardware — Bob provides the raw capability, SmartBob provides the structure, routing, parallelism and verification that turns a single human intent into a production-ready outcome."
