S-06 AI Purchase-Plan Endpoint — Conversation → Real DB Booking ✅ Complete

BobOps built the POST /api/ai/purchase-plan endpoint that takes an AI-generated travel plan JSON and atomically creates a real trips table row and bookings table row in SQLite. This converts a chatbot conversation directly into a confirmed booking visible in the admin dashboard — no mock data.

Agent
⚙️ BobOps
Endpoint
POST /api/ai/purchase-plan
Auth Required
JWT Bearer token
Transaction Steps (Atomic)
1. Parse travel-plan JSON block from AI chat history
2. INSERT into trips table — source='ai', title, type, price, duration, route, highlights, best_season
3. INSERT into bookings table — linked to new trip_id, user email, travel_date, travelers, total_price
4. UPDATE trips.spots_left — decrement by traveler count
5. Return full booking + trip objects → booking appears in "My Bookings" and admin dashboard immediately
  • Endpoint validates JWT auth — unauthenticated users cannot create bookings
  • Parses title, destination, duration, travel_style, travelers, travel_date, price_per_person, price_breakdown, highlights, route, best_season from plan JSON
  • Inserts trip with source='ai' flag to distinguish AI-generated from manually added trips
  • All three DB writes (trip + booking + spots_left decrement) execute as a single logical transaction
  • Newly created booking is immediately visible in admin bookings table — zero async delay
